# v0.1.9

这是针对 v0.1.8 在线升级兼容问题的热修复版本。

## 修复内容

- 修复 v0.1.2～v0.1.7 的内置更新器下载新版后，因历史文件清单仍要求 `OTA_TOOL`、Qt DLL 和 UI Automation 脚本而拒绝启动更新的问题。
- 便携包增加四个零字节兼容占位文件，仅用于满足旧更新器的文件存在性检查。
- 当前程序继续使用 `partition_patch_verify.exe` 完成无界面原生 Patch 还原验证，不会加载或执行这些占位文件，也不会恢复 Qt 运行时依赖。

## 升级说明

- v0.1.2～v0.1.7 用户可直接在工具内检查更新并升级到 v0.1.9。
- 已手动安装 v0.1.8 的用户也可正常升级。
- v0.1.9 自身及后续版本的更新器不再检查兼容占位文件；后续安装包可移除这些文件。
- Patch 文件格式、Manifest 字段和 Gateway OTA 协议均无变化。
