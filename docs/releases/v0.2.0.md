# v0.2.0

这是 OTA 测试平台首次支持多任务自动串行闭环的功能版本，重点减少 Node、Async、Sync 和 Gateway 混合升级测试中的人工重复操作。

## 主要功能

- 新增升级任务队列，可将正向、反向和循环任务混合配置后严格串行执行。
- 队列启动时自动执行预检，每项开始前重新匹配在线设备、起始版本和 Patch 完整性。
- 升级状态机成功后自动复查目标版本，状态机终态和实际设备版本均满足要求才判定任务通过。
- 成功队列自动保存到任务历史，可一键重新导入；同时生成计划汇总报告并关联各子任务报告。
- 增加队列级开始时间、结束时间、总耗时和成功、失败、跳过统计。

## 设备发现与协议

- Node 列表查询支持 `cmd=100 / 0x0E→0x0F` 分页响应，按页聚合、去重并校验总数。
- Node 列表同时显示在线和离线设备，在线设备集中显示在前，离线设备不可选择升级。
- 修复类型批量选择被错误当作列表过滤条件的问题，不同 Node 类型不再被隐藏。
- MQTT 收发记录补齐工具查询请求的 TX 记录，便于对照 Gateway 返回数据。
- Extender 和 Node ID 统一显示为“十进制（十六进制）”。

## Patch 与升级稳定性

- Patch 制作、验证和发布状态增加明确的动态提示，重复发布失败会在界面直接显示原因。
- 修复完整镜像与 Patch 切换后版本信息残留、正反向队列版本衔接及预检原因不明确的问题。
- 修复任务失败后状态机进度仍持续刷新的问题。
- 多 Extender Node 任务严格校验每个目标 Extender 均存在符合条件的在线 Node。
- Gateway 包来源展示按设备类型区分，避免将 Gateway 升级误标为 Sync 缓存。

## 界面与易用性

- 升级页调整为“升级任务配置 + 升级任务队列”和独立升级状态机布局，适配 1K 及更高分辨率。
- 统一功能区域蓝色底框、标题字号、任务时间格式、循环任务底色和按钮尺寸。
- 全局运行日志支持最小化；任务完成恢复结果弹框；所有应用弹框增加 Windows 原生窗口阴影。
- 日志分析会在恢复配置和点击浏览时检查目录是否存在，失效路径自动清理并回退到最近可用目录。

## 升级说明

- v0.1.9 及更早版本可通过工具内更新直接升级到 v0.2.0。
- v0.2.0 不再携带旧版 `OTA_TOOL`、Qt DLL 和 UI Automation 脚本占位文件。
- 现有 Patch 文件格式、Manifest 字段和 Gateway OTA 下发报文保持兼容。
- 使用分页 Node 查询时，Gateway、Sync、Async 固件需与工具端当前 `0x0E/0x0F` 数据结构保持一致。
