# v0.2.1

这是 OTA 测试平台的稳定性与诊断体验更新，重点提升长时间循环测试、Node 任务预检和协议不一致场景的可定位性。

## 循环任务与耗时

- 循环任务失败、超时或取消时，结果明确显示失败轮次、总轮数及正向或反向阶段。
- 队列、阶段和子任务耗时改为自适应中文格式，按实际时长显示毫秒、秒、分钟或小时。
- 循环任务的最终结果和计划子报告保留同一份轮次信息，避免只能通过全局日志反查。

## Node 任务预检

- Node 起始条件不满足时，按 Extender 和 Node 列出具体原因，包括离线、类型不匹配、版本不匹配、RSSI 不达标及固定目标未返回。
- 修复离线 Node 在部分条件组合下可能被误判为动态匹配目标的问题。
- 添加 Node 任务时检查当前勾选结果，混入异类型 Node 会阻止加入队列，并显示具体 Extender、Node ID、实际类型和要求类型。

## 协议诊断

- 对旧版非分页 `cmd=100 / 0x0F` Node 列表响应给出明确的不兼容提示，不再仅显示笼统的分页信息非法。
- 工具仍严格使用新版四字节分页头，不对旧版数据进行静默兼容；出现提示时需升级 Extender 或异步板固件。

## 日志交互

- 全局日志位于底部时保持自动跟随，向上滚动离开底部后暂停查看。
- 使用滚轮回到底部后自动恢复跟随，按 Enter 回到最新日志的操作保持不变。

## 升级说明

- v0.2.0 可通过工具内更新直接升级到 v0.2.1。
- Patch 文件格式、Manifest 字段、Gateway OTA 下发报文和测试计划配置保持兼容。
- Node 列表查询要求 Extender 或异步板固件支持带四字节分页头的最新版 `0x0F` 响应格式。
