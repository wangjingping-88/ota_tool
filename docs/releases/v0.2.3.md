# v0.2.3

这是 OTA 测试平台的 Patch 发布热修复版本，解决启用时间戳文件名后，同内容 Patch 无法按不同文件名分别发布的问题。

## Patch 发布修复

- 修复已发布判断仅包含发布地址和 SHA-256、遗漏目标文件名的问题。
- 发布标识现在同时包含 SFTP 目标、HTTP 地址、目标文件名和 SHA-256。
- 内容相同但时间戳文件名不同的 Patch 会作为不同远端文件正常上传和校验。
- 目标文件名、发布位置和内容均相同时仍会跳过重复上传，并保留原有提示。
- 相同文件名但内容发生变化时允许重新上传覆盖。

## 升级说明

- v0.2.2 可通过工具内更新直接升级到 v0.2.3。
- Patch 内容格式、Manifest、升级任务、历史记录和报告数据库保持兼容。
