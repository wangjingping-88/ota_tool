# v0.2.6

这是 OTA 测试平台的列表操作与历史报告增强版本，重点提升大量报告、Patch、Extender、Node 和日志文件场景下的查找与批量处理效率。

## 历史报告

- 报告列表支持 `Ctrl` 多选和 `Shift` 连续选择。
- 支持按最终状态、今天、近 7 天、近 30 天和关键词筛选报告。
- 关键词可匹配时间、模式、设备类型、状态和版本方向。
- 支持批量归档、恢复和删除；清空按钮只清理当前筛选结果，并在删除前显示确认弹框。
- 报告列表增加两位序号，并实时显示“筛选结果/总数”和已选择数量。

## Patch 与设备列表

- Patch 详情增加两位序号和 Patch 总数。
- Patch 详情支持通过 `Ctrl`、`Shift` 或勾选框批量选择待发布文件。
- Extender 列表增加两位序号和 Extender 总数。
- Node 列表继续显示稳定序号，便于区分相同 ID、不同设备类型的节点。

## 日志分析

- 日志清单增加两位序号，并显示日志总数和已选择数量。
- 支持 `Ctrl` 多选、`Shift` 连续选择、`Delete` 快捷键和“移出所选”批量操作。
- 移出日志只影响本次分析清单，不会删除磁盘源文件。

## 升级说明

- v0.2.5 可通过工具内更新直接升级到 v0.2.6。
- Patch、升级任务、历史记录、报告数据库和本地设置保持兼容。
