# v0.2.9

本版汇总 v0.2.8 之后尚未正式发布的 IPM 升级适配，并修复 MCU 长时间升级的工具超时、同步广播预检误用在线目标规则等问题。

- IPM MCU 读取 `IPMAPP01` 信息头和内嵌版本，烧录与 OTA 统一导入、发布完整 `rtthread.bin`。下载与校验覆盖整包；设备只安装 APP，包内 UBoot 不通过 OTA 更新。正反向完整镜像可用于单次和循环任务。不再使用无 UBoot 测试模式、手填版本或工具侧 APP 提取。
- IPM 网关、WIoTa、MCU 完整镜像统一在 `0x9F00` 使用 `IPM+type+version` 标识，类型分别为 8、2、3。WIoTa 差分包使用独立 `ipm-wiota` 名称和模式清单；EcoLink 与传统模式保留各自规则。A/B 入口可直接导入网关和 MCU 两份完整 BIN。
- IPM 的 MCU 完整镜像门限固定为 256 KiB，仅在 IPM 设置中显示。导入、发布和升级前检查均核对包格式、版本与哈希。
- IPM 同步广播不再依赖在线鉴权列表或旧版本匹配才能通过预检；定向升级继续检查目标。广播有目标快照时升级后逐台复查，没有快照时仅以本次任务 `cmd=9` 最终成功确认，并明确提示未逐台复查。
- 网关每秒上报的 `cmd=1` 心跳不再刷入 MQTT 收发记录；页面显示计数，每次收到时以红心和 `+1` 提示。
- IPM MCU 慢速整包升级按有效字节或阶段进度维护无进度等待窗口，默认连续 30 分钟无进度才超时，并设 24 小时总上限。单次、循环和队列共用同一超时监视器；下发给网关的 `timeout_s`、同会话 `cmd=9` 最终成功门槛及其他模式的超时规则不变。

## 升级前注意

IPM 固件需按新的镜像标识重新构建，旧 IPM 差分包需重新制作。MCU 首次迁移需通过烧录器安装支持完整包的 UBoot 基线；后续 OTA 不更新 UBoot。旧 APP-only 文件不能用于当前完整包流程。详细格式和操作见 [IPM 模式升级说明](../IPM模式升级说明.md) 与 [镜像内嵌版本识别规则](../IPM镜像内嵌版本识别规则.md)。

## 验证范围

Release 编译、Core/App 冒烟测试及在线更新测试覆盖模式隔离、六份双版本固件导入、完整包和差分包、广播/定向预检、MCU 持续传输与停滞超时。MCU 实板升级曾完成设备侧闭环，但旧工具提前超时；本版的超时修复和同步广播队列仍需实板复测。日志分析见 [MCU 升级成功但工具超时](../IPM_MCU升级成功但工具超时.md)。
