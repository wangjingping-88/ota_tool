## 更新内容

### Node Patch 按设备类型独立命名

- Node Patch 不再统一使用 `node` 前缀，改为具体设备类型前缀，避免多种 Node 类型使用相同版本号时生成的差分包互相覆盖。
- 当前类型前缀包括：`room-light`、`switch`、`socket`、`dtu`、`street-light`。
- 例如室内灯控正向 Patch 为 `room-light-v1-to-v2.patch`，电源插座正向 Patch 为 `socket-v1-to-v2.patch`；反向 Patch 同样使用对应类型前缀。
- Manifest 的 `patch_type` 同步记录具体设备类型，导入和发布时能够准确区分不同 Node 类型。
- Server、Extender A、Extender S 和 Gateway 的现有 Patch 命名保持不变。

## 兼容与升级说明

- 工具仍兼容导入旧版本生成的 `node-vX-to-vY.patch` 及其 `patch_type=node` Manifest；重新制作时将自动使用具体设备类型前缀。
- 已安装 v0.1.2～v0.1.6 的用户可以直接使用工具内“检查更新”下载并安装 v0.1.7。
- v0.1.0 或 v0.1.1 仍需先手动升级到 v0.1.2 或更高版本，之后即可使用工具内在线升级。
