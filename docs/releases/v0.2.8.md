# v0.2.8

本版本加入 IPM 升级工作流，并将 EcoLink 的 Extender 查询与固件类型切换到 WIoTa 2.0 协议。

## IPM 升级

- 新增 IPM 模式的网关、倾角定位同步端和 MCU 升级任务；模式设置、目标、队列和历史报告分别保存。
- MCU 完整 `.bin` 仍从 PATCH 中心「导入已有 Patch」导入，无需另附 `.ipm.json`；保留原文件名，完整包发布按长度、哈希和模式校验。
- MCU 增加「无 uboot 验证模式」和「正式模式」。前者供当前固件验证下载、存储与校验，不将下载完成视为真正升级成功；后者要求镜像内可识别版本及正式 APP 向量。
- 当前 MCU 固件尚无内嵌版本标识，因此正式模式暂不能创建 MCU 升级任务。待固件提供标识和引导流程后，再接入自动版本识别与启动后校验。
- IPM 仅显示网关和同步端 Patch 门限，默认分别为 2 MiB 和 52 KiB；MCU 完整 APP 固定上限 224 KiB。

## EcoLink 2.0 适配

- 按最新设备类型定义解析固件：异步端 2、同步端 3，Node 为 4～63；类型 2/3 不再作为自定义 Node 使用。
- Extender Node 列表查询改为 `0x18 → 0x19`，信息查询改为 `0x27 → 0x28`；应用帧固定头的四个字段各占 6 位，并按 2.0 属性位解析可选字段。工具不再回退旧应用帧。
- 修复 Gateway 鉴权列表中同步端 `device_type=2` 被误按应用帧 `ExtenderS=3` 过滤、刷新后显示 0 个 Extender 的问题；升级前校验也使用鉴权类型。
- Node Patch 门限调整为 124 KiB，路灯控制器为 112 KiB；其他设备门限保持原值。

## 升级说明

- v0.2.7 可通过工具内更新升级到 v0.2.8。历史报告按模式显示，原有报告数据不会删除。
- 使用 EcoLink 2.0 查询时，Gateway、Extender 与工具需使用相匹配的 2.0 协议固件；1.0 应用帧不再兼容。
- IPM 无 uboot 模式只用于当前下载联调。正式 MCU 升级须等待固件版本标识与引导程序就绪，并完成实板验收。
