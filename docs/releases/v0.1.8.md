## 更新内容

### 原生 Patch 还原验证

- 使用无界面的 `partition_patch_verify.exe` 完成 Patch 分块解析、LZzip/BSDiff 还原、CRC16-USB 和目标镜像一致性校验。
- Patch 制作、导入验证、发布和升级统一使用原生验证结果作为门禁。
- 删除 `OTA_TOOL.exe`、Qt 运行时和 UI Automation 脚本依赖，便携包体积明显缩小。
- 发布和在线更新流程新增原生验证器及第三方许可证文件完整性检查。

### 界面与标识显示

- 启动时根据当前显示器工作区和 DPI 调整窗口尺寸，避免窗口底部落入 Windows 任务栏区域。
- 在低分辨率或窄窗口下压缩导航、页眉、日志和页脚，并为升级任务提供“任务配置/升级状态”单栏切换。
- Extender ID、Async 地址和 Node ID 统一显示为“十进制（十六进制）”。

### Node 升级门禁

- 多个 Extender 同时参与 Node 升级时，每个已勾选 Extender 都必须至少包含一个在线、类型和版本匹配的已选 Node。
- 任一已选 Extender 没有合格 Node 时，正向、反向和循环升级按钮保持禁用，并在启动校验中提示具体 Extender。
- 取消勾选 Extender 后同步清除其 Node 目标，防止持久化或筛选产生残留目标。

## 兼容与升级说明

- Patch 文件格式、Manifest 字段和 Gateway OTA 协议保持不变。
- 已安装 v0.1.2～v0.1.7 的用户可以通过工具内“检查更新”直接升级到 v0.1.8。
- v0.1.0 或 v0.1.1 仍需先手动升级到 v0.1.2 或更高版本，之后才能使用工具内在线升级。
