# OTA 测试平台独立仓库迁移记录

## 迁移范围

本次落实在线升级方案的第一阶段，将桌面工具从 EcoLink 单体仓库迁移为可独立构建的目录结构。原 `tools/ota_tool` 暂时保留，待独立仓库持续验证稳定后再决定是否移除。

## 已完成

- 应用、核心库和冒烟测试分别迁入 `src`、`tests`。
- Patch 还原脚本、日志分析脚本迁入 `scripts`。
- `bsdiff_cmd.exe` 迁入 `assets/native`，项目通过相对路径引用。
- 移除运行时对 `D:\code\EcoLink` 的固定路径依赖。
- 增加统一版本 `0.1.0`、独立发布脚本、Git 忽略文件和 Windows CI。
- 保留在线升级设计文档，供后续实现 `OtaTool.Update` 与 `OtaTool.Updater`。

## 验证口径

1. 在独立目录执行解决方案还原与 Release 构建。
2. 运行 `OtaTool.Core.SmokeTests`。
3. 发布 `win-x64` 自包含预览。
4. 全仓检索不得再依赖 `D:\code\EcoLink` 或原父目录脚本路径。

## 未包含

本阶段不创建 GitHub 远端、不提交代码，也不实现自动下载和替换程序文件；这些属于在线升级方案的后续阶段。
