# IPM 完整包发布校验

更新日期：2026-10-13；适用工具版本：v0.2.9。

## 当前规则

MCU BIN 不需要用户提供外部清单。工具先在统一偏移 `0x9F00` 读取 `IPM+type+version`，要求 MCU 类型3，再校验 `0x8000` 安全头中的版本、型号、CRC、长度和向量，两处版本必须一致。原样保存完整固件和本地项目记录用于发布。烧录与 OTA 使用同一全包；设备 UBoot 校验整包后只安装 APP，前32 KiB不变。

发布确认和实际上传前共用校验：核对当前 IPM 工作区、包目标/类型、内嵌版本、长度、MD5 与 SHA256。版本未知、清单伪造版本、未经验证或确认后被替换的文件均拒绝发布。差分包继续要求有效 `.json` 清单。

## 历史问题与回归

早期 MCU 无信息头，导入标记未验证，发布误把完整包当成缺少差分清单。曾临时允许未知版本的下载联调包发布。v0.2.9 接通实际信息头识别并删除该临时放行路径，所有 MCU 包均执行正式校验。

回归覆盖无外部清单 APP 导入及目录恢复、完整 BIN 原样导入与整包哈希、正式包进入发布确认、篡改文件/版本拒绝发布、无效差分包拒绝发布。调试时沿导入、目录恢复、发布确认、上传、入队及执行检查所有入口，不能只修复第一道门禁。

发布前的本地预览曾采用工具侧 APP 提取，正式 v0.2.9 已改为完整 BIN：升级长度和所有任务哈希均使用整包。UBoot 只允许烧录器更新。
